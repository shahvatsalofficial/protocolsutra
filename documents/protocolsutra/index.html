Why it exists

Three risks that hide until production

Agents trust the tools they are given. Nobody checks the tools.

Silent breakage

A tool’s input schema changes. Agents that call it start failing, and nothing warns you until users complain.

Poisoned tool metadata

Tool descriptions are read by language models. A hostile server can hide instructions in them, or swap them after you approved.

Unprovable claims

“Works with Cursor”, “secure by design”. Claims are cheap. A reviewer needs something they can re-run.

How it works

Files in, evidence out

Every command reads a captured JSON file, evaluates it with pure functions, redacts secrets and writes JSON, Markdown and HTML.

Offline by default

No network, no subprocess, no tool execution, no API key, no telemetry.

Honest verdicts

Four non-pass states. A missing observation is INCONCLUSIVE, never PASS.

Reproducible

Canonical SHA-256 digests. Re-run on the same input and the digest must match.

Proof

Numbers you can reproduce

Every figure is regenerated by npm run evidence. The benchmark publishes the cases it fails.

What this does not prove

  • The poisoning detector is regex-based. Paraphrase, other languages and encodings evade it. We publish those misses on purpose.
  • The benchmark is small (32 cases) and partly written by the rule author. Treat it as optimistic.
  • No live MCP or A2A server is contacted. This is not an official conformance suite and holds no certification.
  • PASS means “nothing blocking found by these checks”, never “secure”.

Quick start

From zero to a report in 60 seconds

Node.js 20 or newer. Nothing else to install.

Create a snapshot

Start from a synthetic fixture, or save your server’s tools/list output.

npx protocolsutra fixture create \
  --kind mcp --out snapshot.json

Run the checks

Structure first, then the security audit.

npx protocolsutra validate --input snapshot.json
npx protocolsutra audit --input snapshot.json

Open the report

JSON for machines, Markdown for PRs, HTML for people.

npx protocolsutra audit --input snapshot.json \
  --format all --out report

Evidence beats opinion.

Open source, Apache-2.0, zero dependencies. Add it to your CI today.
