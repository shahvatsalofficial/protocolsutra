# Roadmap

- **P0 (starter):** offline snapshot checks, replay, reported compatibility matrix, 18 portable skills, reports, local server, tests — working in this repository.
- **P1:** official MCP v2 (`@modelcontextprotocol/client`, `@modelcontextprotocol/server`) live local fixture adapter; real stdio/Streamable HTTP, version negotiation, initialize/discover/call, differential tests; hardened process isolation.
- **P2:** A2A 1.0 official SDK plus inspector/TCK integration, Agent Card discovery, binding negotiation, task lifecycles, streaming, cancellation and error fidelity.
- **P3:** contract diff and redacted immutable replay capsule, cross-client compatibility doctor, verified real runs in CI, authentication/authorization negative tests.
- **P4:** browser dashboard, OTel traces, quality gates, reports/SARIF, HTML snapshots, plugin packaging; production multi-tenant server security review.
- **P5:** community fixture marketplace with signatures, contribution framework, versioned benchmark corpus, supported frameworks beyond initial major IDEs.

A milestone is completed only after runnable code, automated tests and honest compatibility evidence.
